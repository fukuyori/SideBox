# Sidebox

Windowsデスクトップに、デジタル時計と気象庁の天気予報を表示する軽量ウィジェットです。Goの標準ライブラリとWin32 APIだけで動作し、天気にはAPIキー不要の「天気予報 API（livedoor 天気互換）」を利用します。

バージョン: `0.1.4`

リポジトリ: [fukuyori/SideBox](https://github.com/fukuyori/SideBox)

## 機能

- 秒まで表示するデジタル時計と日付
- 今日の天気、最高／最低気温、降水確率、風向
- 天気アイコン付きで横並びにした今日・明日・明後日の予報
- ドラッグによる配置変更、移動完了時の位置保存、次回起動時の位置復元
- ウィンドウの辺・四隅のドラッグによる表示サイズ変更
- 同一ログインセッションでの二重起動防止
- 常に手前、透明度、地域、更新間隔の設定
- Windowsログイン時の自動起動設定
- タスクバーに常駐しないフレームレス表示

## ビルドと起動

Go 1.24以降を用意し、PowerShellで次を実行します。

```powershell
.\build.ps1
.\dist\sidebox.exe
```

起動時に `%AppData%\sidebox\config.json` が自動作成されます。ウィジェットを右クリックすると、天気の更新、設定ファイルの表示・再読込、終了メニューがウィジェット内に表示されます。移動はウィジェット上を左ドラッグします。右上の「×」でも終了できます。

## 設定

```json
{
  "city_code": "130010",
  "refresh_minutes": 15,
  "always_on_top": true,
  "start_with_windows": false,
  "opacity": 0.94,
  "window_x": 32,
  "window_y": 32,
  "window_width": 760,
  "window_height": 425
}
```

`city_code` は気象庁の一次細分区域コードです。初期値の `130010` は東京地方です。ほかの地域のコードは [一次細分区定義表](https://weather.tsukumijima.net/primary_area.xml) で確認できます。

設定を保存した後、ウィジェットを右クリックして「設定を再読込」を選びます。更新間隔は5分以上、透明度は `0.35` から `1.0` の範囲です。表示サイズはウィンドウの辺または四隅をマウスでドラッグして変更でき、幅・高さは表示位置とともに保存されます。`start_with_windows` を `true` にするとWindowsへのログイン時にSideboxが自動起動します。右クリックメニューからオン／オフを切り替えることもできます。

## データ提供元

天気予報には [天気予報 API（livedoor 天気互換）](https://weather.tsukumijima.net/) を使用しています。このAPIは気象庁ホームページで配信されている天気予報をJSONへ編集したものです。当日の最高・最低気温が `null` の場合だけ、同じ予報地点のJMAアメダス実測値で補完します。ネットワークに接続できない場合も時計はそのまま動作し、天気欄にエラーを表示します。
